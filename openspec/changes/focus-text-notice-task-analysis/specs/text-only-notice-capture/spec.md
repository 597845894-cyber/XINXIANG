## Purpose

让学生只通过主动粘贴的文字把校园通知导入本地收件箱，排除图片采集和 OCR 带来的首版交付与隐私风险。

## ADDED Requirements

### Requirement: 首版仅接受文字通知
系统 MUST 仅提供用户主动粘贴文字的通知导入入口，并保存不可变的原始文字作为后续分析和任务核对的依据。

#### Scenario: 导入有效文字
- **WHEN** 用户在快速导入界面提交非空文字
- **THEN** 系统在本机创建一条文字通知、保留原始文字并将其置为待分析

#### Scenario: 提交空白文字
- **WHEN** 用户提交只包含空白字符的内容
- **THEN** 系统拒绝导入并提示用户粘贴有效的通知文字

### Requirement: 首版不提供图片通知导入
系统 MUST 不显示剪贴板图片、本地图片选择、图片预览或 OCR 操作入口；若旧本地调用尝试导入图片，系统 MUST 拒绝该请求且不得创建通知或读取图片内容。

#### Scenario: 用户打开快速导入
- **WHEN** 用户进入快速导入界面
- **THEN** 界面只显示文字输入与导入操作，不显示图片相关控件

#### Scenario: 旧调用请求图片导入
- **WHEN** 本地调用请求导入图片
- **THEN** 系统返回可理解的“不支持图片导入”结果，且不保存图片或创建通知

### Requirement: 文字导入不读取未授权剪贴板内容
系统 MUST 只在用户触发文字粘贴或提交时处理其提供的文字，且不得在后台记录、分析或保存剪贴板内容。

#### Scenario: 应用驻留后台
- **WHEN** 应用驻留但用户未打开文字导入或粘贴文字
- **THEN** 系统不读取、不保存也不分析剪贴板内容
