- [ ] 3.3 实现原始图片和附件的 AES-256-GCM 流式加密存储、读取、校验和异常清理，并验证磁盘文件不可直接读取且篡改会被拒绝
- [ ] 3.4 实现事务化数据仓储和通知/候选/任务状态转换，验证分析失败、应用中断和事务回滚不会留下半成品正式任务或断裂引用

## 5. 本地通知理解流水线

- [ ] 5.1 完成生产 OCR 适配器、图像预处理、分块识别、文字坐标和置信度输出，并用评测集验证清晰截图、长截图、低可信区域和完全失败路径
- [ ] 5.2 实现文本规范化及日期、时间、网址、联系方式、显式地点和材料关键词的规则提取，并用中文标点、全半角和多种日期格式单元测试验证
- [ ] 5.3 实现以通知发布时间和本地时区为输入的日期解析服务，输出时间点或范围、精度、原始表达和歧义原因，并验证今天、明天、本周、下周、月底和近期等边界样本
- [ ] 5.4 完成受约束结构化输出的本地语义模型适配器，支持通知分类、多任务拆分、字段提取和变更意图，并验证无效 JSON、超时、取消和模型崩溃可恢复
- [ ] 5.5 实现字段校验、证据绑定、可信状态、缺失检测和冲突检测，验证模型无法凭空填充无依据字段且高风险不确定字段被正确标记
- [ ] 5.6 实现单并发可取消分析队列和阶段进度事件，把完整结果原子保存为新 AnalysisRevision，并验证重新分析只新增版本、不覆盖用户确认任务
- [ ] 5.7 实现 OCR 文字修正、失败后手工录入、重新分析和版本差异界面，并通过交互测试验证用户可从任何失败阶段恢复
- [ ] 5.8 在完整评测集运行端到端分析，记录分类、时间、字段、多任务准确率及耗时，验证所选阈值能把高风险错误送入人工确认而非静默通过
