## Why

大学生每天需要从微信群中的长文本、截图和反复更新的通知里手工识别待办事项，容易遗漏截止时间、材料要求和后续变更。需要一款完全离线的 Windows 个人通知信箱，把用户主动导入的校园通知整理为可核对、可提醒、可追溯的任务。

## What Changes

- 新增 Windows 桌面端快速导入入口，支持粘贴文字、粘贴截图和选择图片，并保留不可变的原始通知作为依据。
- 新增完全本地的中文 OCR、通知分类、字段提取、多任务拆分、相对日期解析和可信度判断；通知内容及其派生数据不发送到设备外。
- 新增任务草稿确认流程，让用户在任务进入任务表前核对或修改名称、时间、地点、材料、适用对象和提醒设置。
- 新增个人任务表、截止状态、完成状态、原文回溯、通知更新与取消关联，以及应用内和 Windows 本地提醒。
- 新增本地数据保护、离线运行、加密存储、加密备份导入导出和级联删除能力。
- 首版不包含微信群自动监听、多人协作、账号系统、云端同步、外部日历同步、手机 App、微信小程序或自动代办提交。

## Capabilities

### New Capabilities

- `notice-capture`: 用户主动导入文字或截图，管理通知来源、原文、截图和通知发布时间。
- `local-notice-understanding`: 在设备内完成 OCR、通知分类、结构化字段提取、多任务拆分、相对时间解析和不确定性标记。
- `personal-task-management`: 用户确认任务草稿，在个人任务表中跟踪、完成、回溯、接收提醒，并处理通知更新或取消。
- `local-data-protection`: 保证核心功能离线可用，通知数据不离开设备，并提供加密存储、备份恢复和完整删除。

### Modified Capabilities

无。

## Impact

- 新建 Windows 桌面应用、系统托盘和本地提醒集成，不引入服务端、账号或远程业务 API。
- 引入本地数据库、图片文件管理、中文 OCR、本地语义理解、日期时间解析和加密能力。
- 安装包需要携带或首次本地安装所需模型资源，并以 Windows 10/11、8 GB 内存、无独立显卡为最低运行基线。
- 数据结构需要分离原始通知、分析结果与用户确认任务，为以后重新分析、移动端迁移和可选同步保留空间，但本变更不实现同步。
