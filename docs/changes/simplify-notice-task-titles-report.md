# 通知任务摘要聚合变更报告

## 本阶段已完成

- 将同一目标的准备动作聚合为主要任务，实习通知默认生成“完成校友邦上的实习任务”和“提交实习纸质材料（8月31日下午上课前）”两项。
- 在候选详情保留导出、导师评语、联系老师、盖章、拍照、插入报告、装袋等原文动作与证据，并对“上课前”保留待确认状态。
- 增加 `aggregated`（默认）与 `flat_legacy` 本地模式，旧候选可兼容读取，回退不会覆盖历史通知、分析版本或正式任务。
- 修复候选卡片窄窗口中文竖排问题；统一任务筛选、统计、空状态和确认后任务可见性。
- 增加不同截止时间、不同提交对象、单任务、无日期通知样本，并扩展离线评测字段。
- 本地缓存目录 `.corepack/`、`.rustup-home/`、`.local-build/`、`.npm-cache/` 已加入 `.gitignore`，开发过程未使用 C 盘缓存或模型目录。

## 验证结果

- `corepack pnpm test`：通过。
- `corepack pnpm build`：通过，产物位于项目目录 `dist/`。
- `corepack pnpm exec eslint src --max-warnings 0`：通过。
- `rustfmt --check`：通过。
- Rust 测试阻塞原因：`openssl-sys` 的 vendored OpenSSL 构建在现有 Windows 工具链中调用 `nmake.exe` 失败，不是业务断言失败。

## 人工验收入口

1. 在 E 盘项目目录运行开发版：`corepack pnpm dev`；如需桌面壳，使用项目已有 Tauri 启动方式。
2. 导入纯文字通知，确认分析结果最多保留主要事项，详情可展开查看动作与证据。
3. 确认候选后切换任务表“全部任务”，检查无日期任务也能显示，侧栏统计与列表一致。
4. 在设置中切换 `task_summary_mode` 为 `flat_legacy`，重新分析同一通知，确认仅影响新候选生成，不改变历史任务。
5. 断网运行上述流程并检查应用网络活动，确认通知文本和本地任务数据不离开设备。
