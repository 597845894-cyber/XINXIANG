## 安装与离线

1. 记录安装前应用数据目录是否存在，并运行安装程序。
2. 断开网络后启动应用，确认不要求登录、许可校验或远程服务。
3. 在“快速导入”导入合成文字通知，确认收件箱出现待分析记录。
4. 确认快速导入界面不提供截图、图片选择或 OCR 入口。
5. 打开“设置”，确认模型资源状态和本地安全状态可查看。

结果：`待用户填写`

## 托盘、提醒与恢复

1. 关闭主窗口，确认进程驻留系统托盘并可重新打开。
2. 为合成任务设置一个近期提醒，确认应用内通知中心收到提醒；若系统通知权限不可用，确认应用内降级入口可用。
3. 选择“彻底退出”后重新启动，确认错过提醒按任务合并补发且不重复轰炸。
4. 创建本地加密备份，使用正确口令预检并恢复；再用错误口令预检，确认现有数据不变。

## 升级、回滚与卸载

1. 在安装前保存当前版本号、安装目录和用户数据备份。
2. 安装后续版本或重新安装同版本，确认数据和模型资源检查结果符合预期。
3. 若升级失败，使用安装前备份恢复，确认收件箱、任务和提醒可读取。
4. 从 Windows“应用和功能”卸载，记录应用文件是否移除。
5. 检查卸载选项是否明确区分“保留加密数据”和“永久删除数据”；未经用户确认不得删除数据。
