# 第九阶段：视觉验收记录

## 检查范围

关键流程包括：收件箱筛选、快速导入文字、截图预览、通知详情、候选核对、任务表六个视图、提醒中心、设置中的备份恢复和删除确认弹窗。

## 视口与缩放

| 环境              | 结果       | 记录                                         |
| ----------------- | ---------- | -------------------------------------------- |
| 1366 × 768，100%  | 待人工确认 | 检查导航、表格、固定按钮、弹窗和截图预览     |
| 1920 × 1080，100% | 待人工确认 | 检查内容最大宽度、空白分布和长文本换行       |
| Windows 缩放 125% | 待人工确认 | 检查按钮文字、表单标签和弹窗底部操作区       |
| Windows 缩放 150% | 待人工确认 | 检查截图预览、任务字段和滚动区域是否仍可操作 |

## 人工入口

在项目目录运行 `pnpm dev`，打开终端显示的本地地址。依次执行上述关键流程，并记录每个视口下的异常；若发现问题，截图文件只保存到本地验收目录，不提交到 Git。真实桌面缩放检查使用 `pnpm tauri dev`。

当前已具备响应式 CSS 和固定窗口最小尺寸约束，但没有在 Windows 125%/150% 显示缩放下形成可签署的人工记录，因此任务 9.6 保持未完成。
