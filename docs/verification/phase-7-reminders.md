# 第七阶段：本地提醒与后台生命周期

## 本阶段新增

- 提醒记录支持按任务增删改，使用唯一幂等键避免重复创建。
- 任务完成或取消时，在同一数据库事务内取消未来提醒。
- 应用启动后及托盘驻留期间每 15 秒扫描到期提醒；提醒被原子标记为已触发，重复扫描不会重复产生事件。
- 应用内通知中心接收本地提醒事件，可点击跳转任务表；通知内容只显示通用提醒文案，不展示通知正文、截图或其他敏感字段。
- 启动扫描会处理应用关闭期间错过的提醒；已完成或已取消任务不会补发。
- 设置页增加提醒启停和开机启动偏好（保存在本机），关闭主窗口仍隐藏到托盘，彻底退出时提醒暂停。
- Windows 通知权限不可用时，应用内通知中心仍可作为降级入口。

## 人工验收入口

1. 在项目目录运行 `pnpm dev`，打开 `http://127.0.0.1:1420/`。
2. 进入“任务表”，对任意待办任务点击“提醒”，输入未来时间并保存；再次点击可删除该提醒。
3. 将时间改为当前时间之前，等待最多 15 秒，点击右上角铃铛，应看到“有一条任务提醒需要查看”，点击后跳转任务表。
4. 对仍有未来提醒的任务点击“完成”或“取消”，再次添加提醒列表应为空或提醒状态为已取消。
5. 在“设置”关闭“本地提醒”，再次触发提醒时应用内通知中心不新增内容；重新开启后可继续接收。
6. 关闭主窗口后从托盘重新打开，确认应用仍驻留；选择“彻底退出”后，提醒会在下次启动扫描时继续处理。
