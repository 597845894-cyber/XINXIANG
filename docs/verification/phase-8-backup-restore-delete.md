# 第八阶段人工验收

本阶段新增了完全本地的加密备份与恢复，以及通知删除流程。通知正文、附件和任务不会被上传到网络。

## 本阶段功能

- 使用至少 8 位备份口令，通过 Argon2id 和 AES-256-GCM 创建单文件加密备份。
- 备份包含加密数据库、加密附件、当前 Windows 用户的密钥包装和版本化清单；备份预检会校验口令、完整性和版本，恢复前展示通知、任务和附件数量。
- 恢复先在隔离目录验证数据库和密钥，再替换当前数据；空间不足、文件损坏或口令错误时不会开始替换。
- 通知详情提供两种双重确认删除方式：删除所有关联数据，或保留任务并删除原文。后者会在任务表标记“原文依据已删除”。
- 设置页提供备份提示以及卸载时保留加密数据或永久删除数据的说明。

## 验收入口

1. 启动应用后进入“设置”，在“备份与恢复”填写一个不存在的本地 `.xinxiang` 文件路径和至少 8 位口令，点击“创建备份”。
2. 在右侧使用相同路径和口令点击“预检备份”，核对数量摘要；勾选确认后点击“确认恢复”。
3. 使用错误口令再次预检，确认提示无效且收件箱数据保持不变。
4. 在“收件箱”选择一条通知并点击“删除通知”。分别检查“删除全部关联数据”和“保留任务，只删原文”。
5. 对保留任务的方式，打开“我的任务”，确认任务存在、显示“原文依据已删除”，并且无法重新打开该通知。

## 当前限制

备份容器本身使用独立口令加密，但包含受 Windows DPAPI 保护的应用主密钥。因此完整恢复目前面向同一 Windows 用户上下文；跨 Windows 用户或跨设备恢复尚未实现，也没有任何云端同步或微信监听。

## 自动检查

- 前端格式检查、Vitest 测试和生产构建通过。
- Rust 格式检查通过。
- Rust 单元测试与 Clippy 在当前电脑因既有 SQLCipher/OpenSSL 构建依赖缺少 `perl` 而无法完成；该限制需要在具备 Perl 的 Windows 构建环境复验。
