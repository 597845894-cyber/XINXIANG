# 第一阶段 Windows 交付检查

## 构建内容

- 应用：校园信箱 0.1.0
- 安装目标：NSIS
- 模型资源：`xinxiang.placeholder-model`，仅验证本地资源随包安装，不包含推理权重或用户数据
- 核心运行条件：无需登录、无需业务服务端、无需远程模型许可

只有干净 Windows 10 或 Windows 11 虚拟机中的安装、断网启动、资源存在和卸载均通过后，OpenSpec 任务 1.5 才能标记完成。

## 当前阻塞

- Tauri 发布版应用已在低内存单作业模式构建成功。
- NSIS 封装需要首次从 Tauri 官方 GitHub Release 下载 `nsis-3.11.zip`；Tauri 下载和系统下载均因连接重置失败。
- 当前主机未检测到 Hyper-V、Windows Sandbox、VirtualBox、VMware 或 QEMU，无法执行干净 Windows 10/11 安装与卸载验收。

## 可重复步骤

1. 将生成的 NSIS 安装程序复制到未安装开发工具的干净虚拟机。
2. 断开虚拟机网络后运行安装程序，记录安装结果和安装目录。
3. 启动校园信箱，确认主窗口可打开且不要求登录或联网。
4. 确认安装目录内存在 `models/placeholder-model.txt` 和 `models/manifest.json`。
5. 关闭主窗口，确认进程仍驻留；通过托盘重新打开，再选择“彻底退出”。
6. 从 Windows“应用和功能”卸载，确认程序文件被移除，并记录用户数据保留策略的实际表现。
