# 第三阶段：本地数据与安全基础

## 本阶段结果

- 使用 SQLCipher 创建加密数据库，并完成通知、附件、分析版本、任务候选、任务、提醒和关系记录的版本化迁移。
- 图片和附件改为 AES-256-GCM 分块加密；每个附件使用独立随机密钥，检测到篡改或异常时拒绝读取并清理临时文件。
- 通知、候选和正式任务的跨表变更使用事务，失败时不会保留半成品任务。
- 日志接口仅允许错误码、组件版本和耗时区间，不接收通知正文、文件路径、任务字段或密钥。
- 前端禁止远程脚本、字体、图片和业务网络请求；更新器默认关闭，且不能接触业务数据。

## 自动验证

- Rust 单元测试：25 项通过。
- 前端合同和界面测试：22 项通过。
- 前端格式检查、静态检查和生产构建通过。
- OpenSpec 严格校验通过。

## 人工验收入口

启动桌面开发版后，打开“设置”，在“本地安全检查”一栏点击“运行检查”。成功时页面会显示当前 Windows 用户保护、SQLCipher、AES-256-GCM 和业务联网禁用均已验证。

本阶段仅建立安全与存储基础，尚未开放通知导入、截图 OCR 或任务分析流程。
