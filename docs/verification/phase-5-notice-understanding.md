# 第五阶段：本地通知理解流水线基线报告

## 本次加入

- 新增本地分析模块，统一处理文字通知和加密截图输入。
- 增加离线 OCR 适配器基线：支持 PNG/JPEG/WebP，输出识别行、归一化坐标、置信度和低可信标记；无法提取文字时返回明确失败码。
- 增加文本规范化和规则提取：中文全半角标点、网址、手机号、地点、材料、适用对象、是否必须、相对日期表达。
- 增加通知分类和多任务候选：必须完成、日程安排、自愿参与、结果或变更、仅供知晓。
- 增加受约束模型 JSON 解析边界，覆盖无效 JSON、超时、取消和模型崩溃错误。
- 增加分析进度/完成事件、单并发分析队列和按通知取消请求；分析结果以新的 `AnalysisRevision` 原子保存。
- 收件箱详情页增加“开始分析”、分类可信度、OCR 文本、任务候选和失败提示。

## 当前边界

本阶段提交的是可验收的离线基线。当前 OCR 使用本地 fixture 适配器验证数据流和可信度边界，不等同于生产 ONNX 推理；语义路径使用确定性规则回退，不调用千问 API，也不会联网。完整生产 OCR、真实本地模型推理、复杂日期范围/冲突检测、OCR 文字修正与端到端评测仍列在后续任务中。

## 人工验收入口

1. 在项目目录运行 `pnpm dev`，打开桌面开发窗口。
2. 进入“快速导入”，粘贴一条包含“提交、明天前、地点、材料”的通知文字并导入。
3. 在“收件箱”打开该通知，点击“开始分析”，检查分类、可信度、任务候选、截止日期和原文依据。
4. 使用 `XINXIANG_OCR:` 前缀构造本地截图 fixture，导入图片后检查 OCR 文本和低可信标记。
5. 分析进行时调用取消入口，确认任务返回 `ANALYSIS_CANCELLED`，且数据库没有半成品分析版本。

所有测试数据均留在本机；本阶段不需要 API Key 或网络连接。
