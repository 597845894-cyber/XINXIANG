# 第六阶段：任务核对与管理

## 本阶段已完成

- 任务核对界面展示候选标题、来源通知与分析版本、可信状态、截止时间、字段依据和缺失值。
- 支持候选编辑、确认创建任务、忽略、合并和拆分；候选状态与通知的部分处理状态会写入本地数据库，并记录审计事件。
- 支持正式任务的创建、标题修订、完成、重新打开和取消；每次任务状态或内容变化都会生成新的任务修订记录。
- 支持“今天、本周、即将截止、无确定日期、已完成、全部任务”视图，未完成任务按截止时间排序，过期只作为派生提示。
- 支持本地通知关联建议的展示、证据查看、接受和拒绝，接受或拒绝不会静默改写正式任务。

## 隐私边界

本阶段所有通知正文、候选字段、任务、审计记录和关联证据均通过本地 Tauri 命令访问设备内数据库；浏览器演示模式只使用内置演示数据，不会上传通知内容，也未接入千问 API、微信监听或云同步。

## 人工验收入口

在项目目录执行：

```text
pnpm dev
```

然后打开终端显示的本地地址，按以下顺序验收：

1. 进入“任务核对”，检查高可信候选和缺失日期候选的字段依据与可信状态。
2. 依次测试“保存修改”“合并候选”“拆分候选”“忽略”“确认创建任务”。确认后候选应从列表消失，任务表应出现新任务。
3. 进入“任务表”，切换六个筛选视图；检查无日期、已完成和过期任务的显示，验证完成、重新打开、编辑和取消操作。
4. 在候选详情点击“查找通知关联”，检查建议证据，并分别点击“接受”和“拒绝”；两种操作都不应静默修改现有任务。

如需验证真实 Windows 桌面壳，再执行：

```text
pnpm tauri dev
```
