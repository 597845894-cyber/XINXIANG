# 校园信箱：本地隐私、提醒与备份

校园信箱首版只为单个学生在 Windows 电脑上整理自己主动导入的通知。它不会读取微信群、不监听聊天记录，也不会在后台收集剪贴板历史。

## 数据只在本机处理

- 你主动粘贴的文字、主动选择或粘贴的截图、识别文字、任务、提醒和备份都保存在本机。
- 应用核心不需要登录、账号、联网许可或云端 API。下载模型资源时仅下载模型文件，不会携带你的通知内容。
- 本地数据库和截图附件使用加密保护；当前 Windows 用户启动应用时可以解锁自己的数据。不要把应用数据目录或备份口令分享给他人。
- 首版不提供微信群自动监听、跨设备同步、手机 App、微信小程序、外部日历同步或自动提交表单。

## 导入与核对

1. 从“快速导入”粘贴通知文字，或选择/粘贴一张通知截图。
2. 在“收件箱”确认原文或原图，并补正通知发布时间。
3. 查看分析产生的候选任务、原文依据和可信状态；低可信、缺失或冲突字段需要人工核对。
4. 只有点击“确认创建任务”后，候选才会成为正式任务。你也可以编辑、忽略、合并或拆分候选。

截图识别或任务理解失败时，请保留原图并使用手工录入入口补充文字。系统不会因为识别不确定而静默创建正式任务。

## 提醒行为

- 每个任务可以设置多个本地提醒。
- 关闭主窗口时，应用默认保留在系统托盘，提醒可以继续在后台触发。
- 选择“彻底退出”会停止后台提醒；下次启动应用后，系统会合并检查并补发错过的未完成任务提醒。
- 完成或取消任务会取消该任务尚未触发的提醒。
- 如果 Windows 通知权限不可用，应用内通知中心仍会保留提醒入口。通知内容采用通用文案，不展示通知正文或截图内容。

## 创建与恢复备份

在“设置”的“备份与恢复”中：

1. 选择一个本地 `.xinxiang` 文件路径，并设置至少 8 位的备份口令。
2. 点击“创建备份”。备份文件经过独立口令加密，不能直接阅读其中的通知内容。
3. 恢复前先输入备份路径和口令，点击“预检备份”查看数量摘要。
4. 确认恢复影响后再勾选确认并执行恢复。错误口令、损坏文件、版本不兼容或空间不足时，当前数据不会被替换。

请把备份口令单独妥善保存。当前版本的完整恢复面向同一 Windows 用户上下文，不提供跨设备或跨账号同步。

## 删除数据

删除通知时可以选择：

- 删除通知及其关联的分析、候选、任务、附件和未触发提醒；或
- 保留正式任务，只删除原文依据。

第二种方式会将任务标记为“原文依据已删除”，之后无法重新浏览该通知原文或截图。删除操作需要双重确认。

## 本地模型资源

OCR 与本地语义模型资源存放在 E 盘项目目录的 `local-models` 文件夹中，不会提交到 Git 仓库。模型文件必须通过大小和 SHA-256 校验后才会被应用使用；资源缺失或损坏时，应用会提示从本地完整资源包重新安装。
